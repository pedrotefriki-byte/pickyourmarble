Privacy Policy

Last updated: 10 November 2026

What PickYourMarble is

PickYourMarble is a private tool that generates marble-race videos and uploads them to the PickYourMarble channels owned by its developer. It is not offered to the public.

Data we access

With the account owner's explicit consent, the tool uses the YouTube Data API, the Instagram API and the TikTok Content Posting API only to upload videos and set their title, description and privacy settings on the owner's own accounts. It does not read, collect or analyze viewers' personal data, comments, subscribers or any other user information.

Storage

Authorization tokens are stored only on the developer's own computer and are never shared, sold or transferred to third parties. No data is stored on any server.

Google and YouTube

PickYourMarble uses YouTube API Services. By using it you are also subject to the YouTube Terms of Service and the Google Privacy Policy. Access can be revoked at any time at Google security settings. PickYourMarble's use of information received from Google APIs adheres to the Google API Services User Data Policy, including the Limited Use requirements.

Deleting data

Revoking access in the platform's settings, or deleting the local token files, removes all stored authorization data.
